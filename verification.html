    Verification¶

    Method¶

    Four implementations calculate the game:

    Implementation File Method
    Excel workbook excel/TacklinTheKraken_TheoCalc.xlsx Formulas. Exact.
    Exact calculator gamemath/exact_calc.py Python with exact fractions
    Game engine and simulator web/js/engine.js, sim/simulate.mjs Monte Carlo simulation with the engine of the playable game
    C++ simulator sim_cpp/krakensim.cpp Monte Carlo simulation with its own C++ engine. It made the simulation results of this document.

    The script tools/verify_all.py compares them. It does these checks:

    1. The reel strips obey the design rules. The script also examines each window of each reel: one special symbol at most, and one or more symbols that are not AUS symbols.
    2. The inputs of the workbook are equal to the configuration file.
    3. The results of the workbook are equal to the results of the exact calculator.
    4. The script changes the inputs in a copy of the workbook and does check 3 again. It uses three changed configurations:
      • A: new pays (with 1 OAK and 2 OAK pays), new fish values and weights, new level thresholds, spins and multipliers, multiplier rule fish.
      • B: new reel strips with KEY symbols on all 5 reels, more FS symbols, a bet of 25 credits.
      • C: reel strips with random manual changes that do not obey the gap rule.
    5. The JavaScript engine and an independent Python evaluator give the same result for 40,000 random spins.
    6. The C++ simulator and the JavaScript engine give the same result for 100,000 random spins.
    7. The simulation agrees with the exact values: the total RTP, each RTP component, the trigger frequency and the level probabilities.

    Microsoft Excel also calculated the workbook of version 2.0.0. The result was the same as the exact calculator (total RTP 96.1999706942%).

    Limits of the verification¶

    • The simulation has a standard error of 0.001% RTP. It cannot show a difference smaller than this.
    • The random number generator of the playable game is xoshiro128**. The random number generator of the C++ simulator is xoshiro256++. They are not certified for real money play.
    • An independent test laboratory did not examine this model.
