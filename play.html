    Play the Game¶

    This page holds the playable game, the instructions for the demo suite and the art sets. The game uses the configuration and the art of this document: math version 2.7.0, theoretical RTP 96.2000%.

    Open the game in a full window

    Demonstration

    The game is a demonstration. It does not use real money. The start balance is 10,000 play credits. The random number generator is a demonstration generator. An independent test laboratory did not examine the game.

    Controls¶

    Click in the game before you use the space bar.

    Control Function
    SPIN or the space bar Starts a spin. During a spin, it stops the reels quickly and skips the win presentation.
    AUTO Starts and stops automatic spins
    TURBO Makes the reels and the presentation faster
    Note symbol Sound on or off
    i Shows the paytable and the rules
    DEMO SUITE Opens the demo suite

    The page Game rules gives the rules. Its section "Presentation rules of the playable game" gives the fish value swap, the anticipation and the kraken slow motion.

    Demo suite¶

    The button DEMO SUITE opens the tools that follow.

    Force outcomes. Each button puts one forced result in a queue. The subsequent spin uses the first result in the queue. The demo suite finds real stop positions on the reel strips that give the result. The engine calculates the win as usual.

    Group Results
    Base spin 3, 4 or 5 FS trigger, FS tease, KEY with fish, KEY with FISH3, KEY with FISH4, KEY with no fish, kraken slides out of the window, kraken passes by, large ways win, small ways win, no win
    Free spin KEY with fish, KEY with FISH3, KEY with FISH4, two KEY symbols, kraken passes by, no KEY, large ways win, no win
    Custom Five stop positions that you type
    Free spins now Starts the free spins with no bet, at level 1, 2, 3 or 4

    Art assets. You can select an art set for all symbols. You can also select the set for one symbol.

    Session statistics. Spins, bets, wins, session RTP and other counts.

    Quick simulation. Runs the engine in the browser for 100,000 to 5,000,000 rounds and compares the result with the theoretical values.

    Settings. The fish value swap delay, the anticipation, the kraken slow motion, the random number seed and more credits.

    Math configuration. Shows the configuration as JSON. You can change values and apply them in the game. You can load a configuration file.

    Art sets¶

    The game has 8 art sets. The game starts with set B (Neon flat). You can change the set in the demo suite. The browser keeps your selection. If the default set of the game changes, the game shows the new default set and you select again.

    Theme sets¶

    Asset files¶

    This section is for a person who changes the art in the project folder.

    The assets are SVG files. Each set has its own folder (web/assets/setA to web/assets/setH). The file web/assets/manifest.json lists the sets, the asset names, the default set and the game texts of each theme set.

    Asset Files for each set
    PIC1 to PIC5, AUS1 to AUS5 10
    WILD, KEY, FS 3
    One asset for each fish value 14
    One FISH asset with no number for each tier 4
    Backgrounds (base game and free spins) 2
    Logo 1
    Total 34
    • The script tools/build_assets.py draws all assets with VectorCraft (the vectorcraft-cli tool) and exports them as SVG.
    • If you configure a fish value that has no asset, the game uses the FISH asset with no number and draws the value on it.
    • If an asset file is missing, the game draws a placeholder.
    • To add an asset set, add a folder with the same file names and add the set to manifest.json.
    • The field defaultSet of manifest.json gives the set that the game shows first. The symbol pictures in this document use the same set.
