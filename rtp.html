    Simulation¶

    The simulator plays 1,000,000,000,000 game rounds. One round is one base spin and the free spins that it starts. These results come from the C++ simulator sim_cpp/krakensim (see "Fast simulator" on this page). It used 18 threads. Each thread started on a different seed (20261111 to 20261128).

    Fast simulator¶

    The program sim_cpp/krakensim is a C++ simulator for very large runs. It reads the same configuration file and plays the same game.

    • It plays approximately 90 million rounds for each second on one processor core. On 18 cores, it plays approximately 1.1 billion rounds for each second.
    • The JavaScript simulator plays approximately 5 million rounds for each second on 18 cores.
    • One reel stop is one 32-byte record. A spin reads five records. The program examines only the pay symbols that can make a paying combination.
    • The program selects FISH values only when a KEY symbol is in the window, and only for the FISH symbols in the window. The values are independent of the stop positions. Thus the win distribution is the same as in the game engine.
    • The script sim_cpp/crosscheck.py gives the same reel stops to the C++ program and to the JavaScript engine. All results of 100,000 spins were equal.
    • The run for this document played 1,000,000,000,000 rounds in 959 seconds (16.0 minutes) on 18 threads. It gave an RTP of 96.1992% with a standard error of 0.0009%. The exact RTP is 96.2000%.
    • Each thread starts on a different seed. Thread 0 uses the seed of the --seed option. Each subsequent thread uses the next number. The program prints the seeds and writes them to the result file.
    • The program writes the same result file as the JavaScript simulator. Thus --json build/sim.json puts its results into this document and into the workbook.

    Volatility¶

    Figure Value
    Standard deviation for each round 9.37 x bet
    Base spins with a win 31.26%
    Base spins with a ways win 25.74%
    Base spins with a collect win 6.69%
    Rounds with a win 31.72%
    KEY symbol in the base game 1 in 8.7 spins
    KEY symbol and FISH4 symbol together in the base game 1 in 217 spins
    Largest round win 9,347.2 x bet

    The volatility is medium to high. A small number of large wins holds a large part of the RTP:

    • The base game collect with FISH4 (the kraken) pays 50 or 200 x bet. It gives 32.0% RTP.
    • Levels 2, 3 and 4 give 10.5% RTP. Only 33.5% of the free spins get to level 2.
