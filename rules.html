    Game Rules¶

    This page gives all rules of the game. A person who reads this page can calculate the result of each spin. The examples use real stop positions of the reel strips. A script calculates each example.

    1. The game in brief¶

    • The game has 5 reels and 4 rows. It pays for 1024 ways.
    • One base spin costs the bet of 10 credits.
    • Pay symbols pay for ways from reel 1 to the right. WILD helps to make ways.
    • FISH symbols show credit values. A KEY symbol collects the values of all FISH symbols in the window. The game shows the KEY symbol as a fishing hook and calls it HOOK.
    • 3, 4 or 5 FS symbols start the free spins. The free spins have 4 levels. Each level has a multiplier. KEY symbols open the subsequent level.
    • All wins are in credits.

    2. Bet and game round¶

    1. The bet is 10 credits for each base spin. The player cannot change the number of ways.
    2. A game round starts when the player starts a base spin. The game subtracts the bet from the balance.
    3. A game round has one base spin. If the base spin starts the free spins, the game round also has all free spins.
    4. Free spins do not cost a bet.
    5. The win of a game round is the sum of the win of the base spin and the wins of all free spins.
    6. The game adds the win to the balance. The game has no win limit.

    3. Reels and window¶

    1. Each reel has a reel strip of 100 symbols. The reel strip is a loop: position 0 follows position 99.
    2. A spin selects one stop position for each reel. Each of the 100 stop positions has the same probability. The reels are independent.
    3. The stop position is the strip position of row 1 (the top row). Rows 2, 3 and 4 show the subsequent strip positions.
    4. The window is the 20 symbols that the player sees: 4 symbols on each of the 5 reels.
    5. The game has two sets of reel strips. The base game uses the base reel strips. The free spins use the bonus reel strips. The page Reel strips shows all strips.
    6. On each reel strip there are 3 or more pay symbols between two special symbols. Thus the window of one reel shows one special symbol at most.
    7. A reel strip has no more than 3 AUS symbols in sequence. Thus the window of each reel shows one or more symbols that are not AUS symbols.

    5. Paytable¶

    The values are credits for one way. A bet of 10 credits is necessary for these values.

    Symbol 1 of a kind 2 of a kind 3 of a kind 4 of a kind 5 of a kind
    PIC1 0 0 5 20 80
    PIC2 0 0 4 10 35
    PIC3 0 0 3 8 25
    PIC4 0 0 3 6 18
    PIC5 0 0 2 5 15
    AUS1 0 0 1 2 6
    AUS2 0 0 1 2 6
    AUS3 0 0 1 2 5
    AUS4 0 0 1 2 5
    AUS5 0 0 1 2 5

    A value of 0 means that the combination does not pay.

    6. Ways pays¶

    Rules¶

    1. The game examines each pay symbol independently.
    2. A combination of a pay symbol starts on reel 1. It continues on reel 2, reel 3 and the subsequent reels while each reel shows the pay symbol or a WILD symbol in one or more rows. The row is not important.
    3. The combination ends at the first reel that shows no such symbol. The number of reels in the combination is the "of a kind" number (OAK).
    4. On each reel of the combination, the game counts the pay symbol and the WILD symbols. The number of ways is the product of these counts.
    5. The pay of the symbol is the paytable value for its OAK number multiplied by the number of ways.
    6. Each pay symbol pays one time, for its longest combination only.
    7. Different pay symbols can pay in the same spin. The ways pays of the spin are the sum of the pays of all pay symbols.
    8. WILD substitutes for each pay symbol. One WILD symbol can be part of the combinations of different pay symbols in the same spin.
    9. WILD is not on reel 1. Thus each combination starts with a pay symbol on reel 1, and WILD symbols alone make no combination.
    10. A blocker symbol (KEY, FS, FISH) does not continue a combination.

    Example 1: one way¶

    Stops 67, 71, 37, 93, 71 on the base reel strips:

    Reel 1 Reel 2 Reel 3 Reel 4 Reel 5
    Row 1 AUS1 AUS2 FISH1 PIC3 PIC2
    Row 2 PIC5 PIC4 AUS4 PIC3 AUS5
    Row 3 PIC5 PIC4 AUS1 AUS3 AUS5
    Row 4 AUS5 AUS1 PIC2 AUS3 PIC4
    • AUS1: 3 of a kind. Ways = 1 x 1 x 1 = 1. Pay = 1 x 1 = 1 credits.

    The ways pays of this spin are 1 credits.

    Example 2: WILD and more than one way¶

    Stops 3, 16, 71, 34, 53 on the base reel strips:

    Reel 1 Reel 2 Reel 3 Reel 4 Reel 5
    Row 1 PIC4 PIC4 PIC3 PIC4 PIC1
    Row 2 AUS1 AUS3 AUS5 PIC4 PIC1
    Row 3 AUS1 AUS3 WILD AUS5 AUS5
    Row 4 PIC4 FISH1 AUS4 AUS5 AUS5
    • PIC4: 4 of a kind. Ways = 2 x 1 x 1 x 2 = 4. Pay = 6 x 4 = 24 credits.

    The count for each reel includes the WILD symbols. The ways pays of this spin are 24 credits.

    Example 3: two pay symbols win in the same spin¶

    Stops 46, 63, 35, 31, 68 on the base reel strips:

    Reel 1 Reel 2 Reel 3 Reel 4 Reel 5
    Row 1 AUS2 AUS1 AUS2 PIC4 AUS4
    Row 2 PIC4 PIC1 AUS2 AUS5 PIC2
    Row 3 PIC4 AUS2 FISH1 AUS5 AUS5
    Row 4 AUS4 AUS4 AUS4 PIC4 PIC2
    • AUS2: 3 of a kind. Ways = 1 x 1 x 2 = 2. Pay = 1 x 2 = 2 credits.
    • AUS4: 3 of a kind. Ways = 1 x 1 x 1 = 1. Pay = 1 x 1 = 1 credits.

    The ways pays of this spin are 2 + 1 = 3 credits.

    Example 4: a combination that is too short¶

    Stops 94, 77, 81, 57, 14 on the base reel strips:

    Reel 1 Reel 2 Reel 3 Reel 4 Reel 5
    Row 1 PIC3 PIC3 PIC4 AUS2 AUS1
    Row 2 PIC3 AUS3 AUS3 AUS2 FISH2
    Row 3 AUS2 AUS2 AUS3 FS AUS1
    Row 4 AUS2 PIC5 FISH1 AUS2 PIC1

    AUS2 is on reel 1, reel 2 and reel 4. Reel 3 shows no AUS2 and no WILD. Thus the combination ends after reel 2. The result is 2 of a kind. The paytable value for 2 of a kind is 0. The AUS2 on reel 4 is not part of the combination. This spin has no ways pays.

    7. Fish values¶

    1. Each FISH symbol shows one credit value.
    2. At the start of each reel spin, the game selects a new value for each FISH symbol on each reel strip. This includes the FISH symbols that do not stop in the window.
    3. The game selects each value independently of the other values and of the stop positions.
    4. Each FISH symbol has a list of possible values. A weight table gives the probability of each value.
    5. The base game and each level of the free spins have their own weight tables.
    6. The value that a FISH symbol shows when the reels stop is the value that a KEY symbol collects.

    8. KEY and FISH collect¶

    Rules¶

    1. The game counts the KEY symbols in the full window.
    2. The game adds the values of all FISH symbols in the full window.
    3. Each KEY symbol pays the sum of the FISH values.
    collect win = (sum of the FISH values in the window) x (number of KEY symbols in the window)
    1. The positions of the KEY symbols and of the FISH symbols are not important. A FISH symbol can be on the same reel as the KEY symbol, or on a reel to the left or to the right.
    2. If the window shows no KEY symbol, the FISH symbols pay nothing.
    3. If the window shows a KEY symbol and no FISH symbol, the collect win is 0.
    4. The collect win does not depend on the ways pays. One spin can have ways pays and a collect win.
    5. In the base game, KEY is on reels 1, 2, 3. FISH3 is on reel 4. FISH4 is on reel 5.

    Example 5: collect and ways pays in one spin¶

    Stops 58, 66, 84, 97, 76 on the base reel strips. The FISH symbols show the values in the table:

    Reel 1 Reel 2 Reel 3 Reel 4 Reel 5
    Row 1 AUS3 AUS4 FISH1 = 1 AUS3 AUS2
    Row 2 KEY PIC4 AUS3 PIC1 FISH1 = 3
    Row 3 AUS5 AUS3 AUS3 AUS3 AUS1
    Row 4 AUS5 FISH2 = 25 PIC5 AUS3 AUS1
    • Sum of the FISH values = 25 + 1 + 3 = 29 credits.
    • There is 1 KEY symbol. Collect win = 29 x 1 = 29 credits.
    • AUS3: 4 of a kind. Ways = 1 x 1 x 2 x 3 = 6. Pay = 2 x 6 = 12 credits.
    • Win of the spin = 12 + 29 = 41 credits.

    Example 6: FISH symbols and no KEY symbol¶

    Stops 65, 42, 68, 21, 12 on the base reel strips:

    Reel 1 Reel 2 Reel 3 Reel 4 Reel 5
    Row 1 PIC3 AUS5 AUS1 AUS1 AUS1
    Row 2 PIC3 AUS5 AUS1 FISH1 = 2 AUS1
    Row 3 AUS1 AUS5 PIC3 AUS1 AUS1
    Row 4 PIC5 FISH1 = 1 PIC3 AUS1 FISH2 = 10

    The window shows 3 FISH symbols with a total value of 13 credits. The window shows no KEY symbol. Thus the collect win is 0. This spin has no win.

    9. Win of a spin¶

    The game calculates a spin in this sequence:

    1. Select the stop position of each reel.
    2. Select the value of each FISH symbol.
    3. Calculate the ways pays (section 6).
    4. Calculate the collect win (section 8).
    5. In the free spins, apply the level multiplier (section 11).
    6. In the base game, count the FS symbols (section 10).
    base spin win = ways pays + collect win

    10. Free spins trigger¶

    1. FS is a scatter symbol. The game counts the FS symbols in the full window. The positions are not important.
    2. One reel shows one FS symbol at most. Thus the window shows 5 FS symbols at most.
    3. The table shows the number of initial free spins.
    FS symbols in the window Initial free spins Probability for each base spin Frequency
    3 10 0.005558 1 in 180
    4 15 0.000262 1 in 3,815
    5 20 0.000005 1 in 203,451
    1. Fewer than 3 FS symbols have no function.
    2. The FS symbol has no pay of its own.
    3. The base spin that starts the free spins pays its ways pays and its collect win as usual.
    4. The free spins start after the game pays the base spin.

    Example 7: trigger¶

    Stops 84, 83, 24, 70, 90 on the base reel strips:

    Reel 1 Reel 2 Reel 3 Reel 4 Reel 5
    Row 1 FS FS AUS5 AUS2 AUS1
    Row 2 AUS5 AUS5 AUS5 AUS2 FS
    Row 3 PIC4 AUS5 PIC1 PIC2 AUS4
    Row 4 AUS3 PIC5 AUS4 AUS3 PIC5

    The window shows 3 FS symbols. The game starts 10 free spins. - AUS5: 3 of a kind. Ways = 1 x 2 x 2 = 4. Pay = 1 x 4 = 4 credits.

    The base spin pays 4 credits. Then the free spins start.

    11. Free spins¶

    Reels and symbols¶

    1. The free spins use the bonus reel strips.
    2. The bonus reel strips have no WILD symbol and no FS symbol.
    3. The bonus reel strips have 70 FISH symbols and 5 KEY symbols. The base reel strips have 24 FISH symbols and 3 KEY symbols.
    4. The free spins cannot start more free spins. There is no retrigger.
    5. The rules for ways pays (section 6), fish values (section 7) and collect (section 8) are the same as in the base game.

    Levels¶

    Level KEY symbols necessary (total in the free spins) Spins Multiplier
    1 none 10 / 15 / 20 (initial free spins) x1
    2 3 8 x2
    3 6 8 x5
    4 9 8 x10
    1. The initial free spins are level 1.
    2. The game has a KEY counter. The counter starts at 0 when the free spins start. KEY symbols of the base spin do not count.
    3. Each KEY symbol that lands in a free spin adds 1 to the counter. The counter does not decrease and does not go back to 0 between levels.
    4. The game examines the counter only when all spins of the current level are complete.
    5. If the counter is equal to or more than the threshold of the subsequent level, the subsequent level starts with its number of spins.
    6. If the counter is less than the threshold, the free spins end.
    7. The levels come in sequence. The game does not skip a level, also when the counter is more than the threshold of a higher level.
    8. KEY symbols that land in a level count for all subsequent thresholds.
    9. Spins do not move from one level to the subsequent level. Each level has its own number of spins.
    10. After the last spin of level 4, the free spins end.

    Level multiplier¶

    1. Each level has a multiplier.
    2. The level multiplier multiplies the full win of the spin: the ways pays and the collect win.
    3. The multiplier of a level applies to each spin of that level.
    4. The multiplier does not change the number of KEY symbols.
    free spin win = level multiplier x (ways pays + collect win)

    Fish values in the free spins¶

    Each level uses its own weight tables for the fish values (section 7).

    End of the free spins¶

    1. The free spins end when the counter is not sufficient for the subsequent level, or when the top level is complete.
    2. The win of the free spins is the sum of the wins of all free spins.
    3. The game adds this win to the balance. Then the game goes back to the base reel strips.

    Example 8: level multiplier¶

    A free spin on level 3 (multiplier x5), stops 25, 75, 33, 68, 43 on the bonus reel strips:

    Reel 1 Reel 2 Reel 3 Reel 4 Reel 5
    Row 1 PIC4 AUS3 KEY PIC1 AUS1
    Row 2 PIC4 FISH2 = 15 AUS1 PIC1 FISH4 = 500
    Row 3 FISH1 = 1 PIC4 PIC5 FISH2 = 10 AUS3
    Row 4 PIC1 AUS3 PIC4 AUS3 PIC1
    • PIC4: 3 of a kind. Ways = 2 x 1 x 1 = 2. Pay = 3 x 2 = 6 credits.
    • Sum of the FISH values = 1 + 15 + 10 + 500 = 526 credits. There is 1 KEY symbol. Collect win = 526 credits.
    • Win of the spin = 5 x (6 + 526) = 2660 credits.
    • The KEY counter increases by 1.

    Example 9: two KEY symbols in one free spin¶

    Two reels show a KEY symbol in this spin. Stops 32, 26, 33, 65, 40 on the bonus reel strips, level 1:

    Reel 1 Reel 2 Reel 3 Reel 4 Reel 5
    Row 1 PIC1 AUS2 KEY AUS2 PIC2
    Row 2 KEY PIC4 AUS1 FISH3 = 200 PIC2
    Row 3 AUS3 PIC4 PIC5 PIC1 AUS1
    Row 4 AUS3 FISH2 = 20 PIC4 PIC1 AUS1
    • Sum of the FISH values = 20 + 200 = 220 credits.
    • There are 2 KEY symbols. Each KEY symbol collects each FISH value.
    • Collect win = 220 x 2 = 440 credits.

    13. Questions and answers¶

    Can one spin have ways pays, a collect win and a free spins trigger? Yes. The game pays all of them.

    Does a KEY symbol pay if there is no FISH symbol? No. In the free spins, the KEY symbol adds 1 to the KEY counter in each case.

    Does a FISH symbol pay if there is no KEY symbol? No.

    Can two or more KEY symbols land in one spin? Yes. KEY is on reels 1, 2, 3 in the base game and on reels 1, 2, 3 in the free spins. One reel shows one KEY symbol at most. Thus one spin can show up to 3 KEY symbols in the base game and up to 3 KEY symbols in the free spins. The probability of two or more KEY symbols is 0.47% for each base spin and 1.23% for each free spin. Each KEY symbol collects each FISH value. In the free spins, each KEY symbol adds 1 to the counter.

    Does the multiplier of a level apply to the ways pays? Yes. It applies to the full win of each spin of that level.

    Do KEY symbols of level 1 count for level 3? Yes. The counter is the total for the full free spins.

    Can the free spins go from level 1 to level 3 directly? No. Level 2 comes first.

    Can the free spins start again in the free spins? No. The bonus reel strips have no FS symbol.

    Does the FISH value change between the spin start and the reel stop? The game selects the values at the start of the spin. The reels show the new values 500 ms after the spin start, before the first reel stops.

    14. Presentation rules of the playable game¶

    These rules do not change the result of a spin.

    • Fish value swap. The reels start at the wager. The FISH symbols show their new values 500 ms after the wager. The reels are in motion at this time. No reel stops before the swap.
    • KEY anticipation. If a KEY symbol lands on reel 1, 2 or 3, reels 4 and 5 spin longer and show a glow.
    • FS anticipation. If 2 FS symbols are in the window, each subsequent reel that can show an FS symbol spins longer and shows a glow.
    • Kraken slow motion. This step applies to a reel that shows the KEY anticipation and that has a kraken symbol (FISH4) on its strip. The last 18 symbols before the stop move on the true reel strip. If a kraken symbol comes into the window in this part, the reel decreases its speed to 2.8 symbols for each second. The kraken symbol then stops in the window, or it goes out at the bottom of the window and the reel increases its speed again. A spotlight frame follows the kraken symbol. The step applies to the two kraken values.
    • Win presentation. The game shows the ways pays first, then the collect, then the level multiplier. This sequence does not change the win.
