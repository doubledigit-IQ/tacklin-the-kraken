    Playable Game and Demo Suite¶

    Start the game¶

    1. Open a terminal in the project folder.
    2. Run python3 tools/serve.py.
    3. Open http://localhost:8765/web/ in a browser.

    The built document also holds the game. See the page Play the game. On a website, that page works with no other step.

    The game is a demonstration. It does not use real money. The start balance is 10,000 credits.

    Controls¶

    Control Function
    SPIN or the space bar Starts a spin. During a spin, it stops the reels quickly and skips the win presentation.
    AUTO Starts and stops automatic spins
    TURBO Makes the reels and the presentation faster
    Note symbol Sound on or off
    i Shows the paytable and the rules
    DEMO SUITE Opens the demo suite

    Spin sequence¶

    1. The game takes the bet. The reels start.
    2. After 500 ms, the FISH symbols on the reel strips show their new values. The reels are in motion.
    3. The reels stop from left to right. No reel stops before the fish value swap.
    4. If a KEY symbol is in the window, reels 4 and 5 show the KEY anticipation.
    5. If a kraken symbol comes into the window of a reel with the KEY anticipation, that reel goes into slow motion. The kraken symbol stops in the window or goes out at the bottom.
    6. If two FS symbols are in the window, the subsequent reels show the FS anticipation.
    7. The game shows the ways pays. Then each KEY symbol collects each FISH value.
    8. In the free spins, the game shows the level multiplier.

    Demo suite¶

    Force outcomes. Each button puts one forced result in a queue. The subsequent spin uses the first result in the queue. The demo suite finds real stop positions on the reel strips that give the result. The engine calculates the win as usual.

    Group Results
    Base spin 3, 4 or 5 FS trigger, FS tease, KEY with fish, KEY with FISH3, KEY with FISH4, KEY with no fish, kraken slides out of the window, kraken passes by, large ways win, small ways win, no win
    Free spin KEY with fish, KEY with FISH3, KEY with FISH4, two KEY symbols, kraken passes by, no KEY, large ways win, no win
    Custom Five stop positions that you type
    Free spins now Starts the free spins with no bet, at level 1, 2, 3 or 4

    Art assets. The game has 8 full asset sets. You can select a set for all symbols. You can also select the set for one symbol. The browser keeps your selection.

    Session statistics. Spins, bets, wins, session RTP and other counts.

    Quick simulation. Runs the engine in the browser for 100,000 to 5,000,000 rounds and compares the result with the theoretical values.

    Settings. The fish value swap delay, the anticipation, the kraken slow motion, the random number seed and more credits.

    Math configuration. Shows the configuration as JSON. You can change values and apply them in the game. You can load a configuration file.

    Theme sets¶

    A theme set keeps the function of each symbol and changes its subject. A FISH symbol is then not a fish. The symbol names in the configuration do not change. A theme set can also give its own words for the game texts. The file web/assets/manifest.json holds these words in the field labels of the set.

    The script tools/build_assets.py draws all assets with VectorCraft (the vectorcraft-cli tool) and exports them as SVG.

    If you configure a fish value that has no asset, the game uses the FISH asset with no number and draws the value on it. If an asset file is missing, the game draws a placeholder.

    To add an asset set, add a folder with the same file names and add the set to manifest.json.
