    Base Game Math¶

    Model¶

    • Each reel stops at one of 100 stop positions. Each stop position has the same probability.
    • The reels are independent.
    • The window of a reel at stop s is the strip positions s to s+3.

    For each reel r and each symbol X, the calculation uses the count c(r, X). This is the number of symbols X in the window. The calculation finds c(r, X) for each of the 100 stops.

    Ways pays¶

    For a pay symbol S, let n(r) be the number of S symbols plus the number of WILD symbols in the window of reel r.

    The symbol S gives exactly k of a kind when n(1) to n(k) are more than zero and n(k+1) is zero. The number of ways is then n(1) x n(2) x ... x n(k).

    The reels are independent. Thus the expected number of ways is a product:

    E[ways for exactly k OAK] = M(1) x M(2) x ... x M(k) x Z(k+1)      for k = 1 to 4
E[ways for exactly 5 OAK] = M(1) x M(2) x M(3) x M(4) x M(5)

M(r) = mean of n(r) for the 100 stops of reel r
Z(r) = fraction of the 100 stops of reel r where n(r) = 0

EV(S)   = sum for k = 1 to 5 of  pay(S, k) x E[ways for exactly k OAK]
EV ways = sum of EV(S) for all pay symbols

    The product is correct because the term n(1) x ... x n(k) is zero when one of the counts is zero.

    Condition

    The formula is correct only if reel 1 has no WILD symbol. With a WILD symbol on reel 1, one way can pay for more than one symbol. The engine and the workbook reject such a strip.

    KEY and FISH collect¶

    Let K be the number of KEY symbols in the window. Let N(f) be the number of FISH symbols of type f in the window. Let V(f) be the mean value of FISH type f in the current mode.

    The value of each FISH symbol is independent of the stop positions. Thus:

    EV collect = sum for all FISH types f of  V(f) x E[K x N(f)]

    K and N(f) are sums of the reel counts. Counts on different reels are independent. Counts on the same reel are not independent.

    E[K x N(f)] = (sum of E[k(r)]) x (sum of E[n(r, f)])
              - sum for each reel r of E[k(r)] x E[n(r, f)]
              + sum for each reel r of E[k(r) x n(r, f)]

k(r)    = number of KEY symbols in the window of reel r
n(r, f) = number of FISH type f symbols in the window of reel r

    The last term uses the 100 windows of the reel directly. This formula is correct for KEY symbols on all reels.

    The FISH4 symbol gives the largest part of the collect RTP. A KEY symbol and a FISH4 symbol land together 1 in 217 spins.
