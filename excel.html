    Excel Workbook¶

    Download the workbook (.xlsx, 234 KB)

    Item Value
    File TacklinTheKraken_TheoCalc.xlsx
    Math version 2.3.0
    Theoretical RTP in the workbook (Summary!C9) 96.2000%
    Contents 12 sheets. All results are formulas. There are no macros.
    Program Microsoft Excel, or a different spreadsheet program that calculates the formulas when it opens the file

    Open the file in a spreadsheet program

    The file holds the formulas and no stored results. The spreadsheet program calculates all values when it opens the file. A file preview that does not calculate (for example in an e-mail program) shows empty cells.

    This page gives the short instructions. The page Excel calculation in detail explains each sheet, block and formula.

    Results that the workbook shows¶

    The sheet Summary shows these results for the delivered inputs:

    Cell Component RTP
    Summary!C6 Base game: ways pays 36.1976%
    Summary!C7 Base game: KEY and FISH collect 39.1625%
    Summary!C8 Free spins 20.8399%
    Summary!C9 Total 96.2000%

    The cell Config!C1 shows the total RTP on the same sheet as the inputs.

    Sheets¶

    Sheet Contents
    Summary RTP for each component, key figures, checks, reference values (orange cells)
    Config Inputs: bet, paytable, fish values, weights, free spins, levels, multiplier rule, placement rules
    Reels_Base Inputs: the base reel strips. Checks of the design rules.
    Reels_Bonus Inputs: the bonus reel strips. Checks of the design rules.
    Ways Expected ways pays for each symbol, for the two reel sets
    Fish Mean fish values and the expected collect for each mode
    Trigger Distribution of the FS symbols and the trigger probabilities
    Bonus KEY distribution, level probabilities, expected value of the free spins
    Distribution Win distribution tables from the simulation: RTP and probability of each win band (orange cells), with cumulative values
    Win_Base, Win_Bonus Helper sheets: the count of each symbol in the window at each stop

    Colours¶

    Colour Meaning
    Yellow Input. You can change the value.
    Grey Fixed by the layout of the workbook
    Green Result or check
    Orange Fixed value from an external calculation: the script gamemath/exact_calc.py or the simulation. It is not a formula. It does not change when you change an input.

    The orange cells are on the sheets Summary and Distribution. Use them to compare the results of the workbook with the results of the other calculations.

    How to use the workbook¶

    1. Open the workbook. Excel calculates all formulas.
    2. Change a yellow cell on the sheet Config, Reels_Base or Reels_Bonus.
    3. Read the new RTP on the sheet Summary.
    4. Make sure that all cells in the section CHECKS show OK.

    The reel strip cells have a list of the permitted symbols. The special symbols have a blue background. A red cell in the check columns shows a rule that the strip does not obey.

    Limits¶

    • The workbook has a fixed layout: 5 reels, 4 rows and 100 symbols for each reel.
    • Each FISH symbol can have 4 values or less.
    • The level tables hold 40 spins or less for each level. They hold KEY thresholds of 25 or less.
    • The ways formula is correct only if reel 1 has no WILD symbol.
    • The bonus reel strips must have no FS symbol.

    The sheet Summary shows a message if the inputs do not obey these limits.

    How the workbook is made¶

    The script tools/build_excel.py makes the workbook. It is a client of the public Excel MCP server (github.com/haris-musa/excel-mcp-server, in the folder vendor/excel-mcp-server). The script writes each sheet, format and formula with a tool call to that server (create_workbook, format_range, write_range and others).

    .venv/bin/python tools/build_excel.py

    The script tools/excel_to_config.py reads the yellow cells and writes config/game_config.json.
