    Configuration¶

    The file config/game_config.json holds all math values. The game, the simulator, the exact calculator and the Excel workbook use this file.

    How to change the configuration¶

    There are two procedures.

    Procedure A: change the JSON file.

    1. Change the values in config/game_config.json.
    2. If you changed the reel recipe, run python3 gamemath/gen_reels.py.
    3. Run python3 gamemath/exact_calc.py --json build/theo.json.
    4. Run .venv/bin/python tools/build_excel.py.
    5. Run .venv/bin/python tools/gen_docs.py.

    Procedure B: change the Excel workbook.

    1. Change the yellow cells in the workbook. The workbook shows the new RTP immediately.
    2. Save the workbook.
    3. Run .venv/bin/python tools/excel_to_config.py.
    4. Do steps 3 and 5 of procedure A.

    Procedure C: try a change in the game.

    The demo suite of the playable game has the tool "Math configuration". It shows the configuration as JSON. You can change values there and apply them in the game. This change is for a test only. It stays in the browser and does not change the file.
